# 問い合わせメール分類 仕様

## 1. 目的

建材メーカーの顧客問い合わせメールを自動分類し、振り分け先と優先度を判断する。

## 2. 分類軸1：内容カテゴリ（単一選択）

- 品番特定
- 廃番対応
- 製品仕様
- 納期在庫
- 不具合クレーム
- 見積
- 施工相談

## 3. 分類軸2：発信元

- `external`
- `internal_forward`
- `unknown`

## 4. カテゴリ定義

| カテゴリ | 定義 |
|---|---|
| 品番特定 | 製品名も品番も不明で、対象製品を特定したい |
| 廃番対応 | 廃番に関する問い合わせ全般（廃番かどうかの確認、代替品・後継品の依頼）。対象製品は特定済み |
| 製品仕様 | 仕様確認、および廃番が前提でない同等品・グレード比較 |

## 5. 境界ルール

- 製品名または品番で対象製品を特定できていれば「判明」とみなす
- 品番特定と廃番対応の境界は「対象製品が判明しているか」
- 廃番が前提でない比較は製品仕様

## 6. 複合メール

実データの約7割が複合（複数の用件を含む）。優先順位ルールで主要件を1つ選ぶ。

```
不具合クレーム > 納期在庫 > 品番特定 > 廃番対応 > 見積 > 製品仕様 > 施工相談
```

## 7. スコープ外

- 1通単位の分類とし、スレッド単位の文脈保持は対象外
- マルチラベル化は次段階の課題
